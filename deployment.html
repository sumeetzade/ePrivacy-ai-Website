Deployment & proof of concept

Thirty days, inside your own staging.

  1. Week 1

    Infrastructure & container spin-up

    Deploy Helm charts on private Kubernetes or Docker Compose on local GPU nodes.

  2. Week 2

    Directory & knowledge ingestion

    Connect SAML/SSO and index initial policy or curriculum documents.

  3. Week 3

    Agent configuration & departmental testing

  4. Week 4

Hardware (on-prem)

Minimum 2× NVIDIA A10G / L40S / A100 (40/80GB) for 70B-parameter local inference. Or any existing CPU/RAM cluster if pointing to private cloud endpoints.

Container runtimes

Docker Engine 24.0+ with NVIDIA Container Toolkit, or Kubernetes 1.26+.

Networking

Local access for user endpoints. Outbound internet is optional, required only for remote API model providers.
