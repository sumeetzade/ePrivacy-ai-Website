Model agnosticism & routing

One workspace, any model.

A native abstraction layer supports local open-weights (Llama 3, Mistral Large, Qwen, DeepSeek) and private enterprise endpoints (Azure OpenAI, AWS Bedrock). Route specific departments to private commercial endpoints while sensitive teams stay on local, air-gapped models.

Technical specifications

Inference Engines

Direct integration with vLLM (PagedAttention), NVIDIA Triton, Ollama, or private cloud endpoints (AWS Bedrock, Azure OpenAI).

Model Compatibility

Llama 3/3.3, Mistral/Mixtral, DeepSeek R1/V3, Qwen, Falcon, or any Hugging Face standard weight format.

Vector Search & RAG

Native Qdrant, pgvector, or Milvus integrations; hybrid dense/sparse search (BM25 + BGE/Cohere embeddings).

Access Control (RBAC)

SAML 2.0, OAuth2/OIDC, Microsoft Entra ID, LDAP. Attribute-based document filtering at the vector retrieval layer.

Data Encryption

AES-256 at rest; TLS 1.3 for the internal service mesh (mTLS via Istio or Linkerd).

Auditing & SIEM

JSON structured logging, Prometheus metrics, OpenTelemetry tracing, and syslog integration for Splunk/Datadog.
