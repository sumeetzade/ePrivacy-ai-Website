The commercial philosophy

Adoption should not be penalized.

Traditional enterprise AI software charges per seat or per token. ePrivacy-AI uses an infrastructure-aligned bring-your-own-compute (BYOC) flat license. Your costs stay predictable whether your institution runs 10,000 queries or 10,000,000 queries per month.

How this is calculated

Commercial SaaS: users × seat fee × 12, plus token overage when usage exceeds 20 queries per user per day (users × queries above 20 × $0.008 × 250 workdays). Scales linearly with headcount and usage.

ePrivacy-AI: a tiered annual software license ($36,000 up to 800 users, $48,000 up to 2,000, $58,000 up to 5,000, $78,000 above) plus infrastructure. GPU nodes are estimated from peak concurrency (one node per 25 concurrent users) at $1,800 per node per month in a private cloud VPC or $950 per node per month amortized on-premises. Compute scales sublinearly with continuous batching and quantized inference (vLLM).

Payback is the license cost divided by annual savings. This is an illustrative planning model with simplified assumptions, not a quote. Final pricing depends on your scope.

When a model changes

Can we use open-source models exclusively to eliminate API costs?

Yes. You can run open-weights (such as Llama 3 or Mistral) on your own GPUs with $0 external API token costs.

Can we connect commercial APIs if our security policy permits?

Yes. Route specific departments to private Azure OpenAI or Anthropic endpoints while routing sensitive teams to local, air-gapped models.

What does the license cover?

Platform orchestration, agent engine, web workspaces, connectors and software updates. Implementation and deployment packages (bare-metal setup, Kubernetes, SSO, custom connectors) are a one-time cost.

Do you charge per seat?

No. Add users, faculty, and students without ballooning per-seat software costs.
